이전 도면 보관하기

이전에 작성한 고객 안내문과 홍보 카드는 안내문·홍보 카드 보관하기에서 따로 옮길 수 있습니다.

3D 제품 즐겨찾기는 별도로 보관하기에서 옮겨 주세요.

예전에 에인연에서 저장한 도면을 파일로 내려받고, 모당의 도면 편집기에서 다시 불러올 수 있습니다.

로그인 중 남은 3D 원본 파일

예전 3D 도구에서 로그인하기 직전에 선택한 파일이 이 브라우저에 임시로 남아 있다면 내려받을 수 있습니다. 파일은 원래 로그인 복귀용이며, 이미 사용됐거나 삭제됐다면 찾을 수 없습니다. 완성된 3D 결과를 복구하는 기능은 아닙니다.

시작하기 전

예전에 GitHub 주소에서 저장했던 같은 기기와 브라우저에서 열어 주세요. 브라우저 저장소는 다른 주소와 분리되며 삭제한 자료는 찾지 못할 수 있습니다.

도면은 이 기기에서 선택한 파일로만 저장하며 서버에 보내지 않습니다. 내려받기는 기존 도면을 삭제하지 않습니다. 형식이 손상된 자료는 복구를 위해 원본 텍스트로 보관할 수 있습니다.

    도면과 폴더 함께 받기

    묶음에는 도면의 폴더, 즐겨찾기, 휴지통 표시와 수정 시각이 들어가요. 다른 도면 편집 탭을 닫은 뒤 받아 주세요. 목록에 없는 도면은 위의 ‘이 기기에 저장된 도면 찾기’에서 한 장씩 받아 주세요.

    모당에서 열기

    개별 도면과 묶음 파일 모두 모당에서 도면 가져오기에서 열어 주세요. 개별 도면은 내려받은 파일 이름을 그대로 두세요.

    같은 도면을 다시 가져오면 건너뛰어요. 같은 번호에 내용이 다른 개별 도면은 별도 사본으로 추가할 수 있어요.

    개별 도면 파일에는 북마크와 휴지통 상태가 포함되지 않습니다. 이 화면은 업무의 임시 저장 내용을 옮기지 않습니다.

    업무 초안은 GitHub 주소의 업무 초안 보관 화면에서 별도로 확인해 주세요. 기존 로그인이 유효해야 합니다.
